# Используемое железо:
* arduino nano - мозг системы
* lcd 1602 - экранчик для вывода информации
* bmp280 - давление воздуха
* ds3231 - часы реального времени
* htu21d - температура и влажность воздуха
* кнопка - для переключения между экранами

# Экраны:
* ##### заставка - длится пару секунд при включении:
```
Weather Station
     v1.0
```

* ##### экран 1 - дата/время + день недели:
```
Пятница 04.09
  12:34:56
```

* ##### экран 2 - сводка:
````
23.5C 45% 1013
  Комфортно
````
